# CalcX

CalcX is a modern, lightweight calculator and productivity workspace designed for quick calculations, scientific work, unit conversions, and everyday numeric tasks in a clean browser-based interface.

Built as a static web application, CalcX delivers a fast and intuitive experience without requiring a build pipeline or complex setup. Whether you need a basic arithmetic calculator, scientific functions, engineering notation, or utility calculators for finance and life tasks, CalcX brings the tools together in one place.

[View the live site](https://sidhaaarth24.github.io/calcx/)

## Features

- Standard, scientific, and engineering calculator modes
- Expression-based calculations with keyboard and mouse input
- Percentage, memory, and recent history support
- Unit conversion tools across multiple categories
- Utility calculators for finance, health, statistics, travel, and more
- Light and dark theme toggle
- Responsive layout for desktop and mobile browsing
- No installation or framework setup required

## Getting Started

### Option 1: Open directly in a browser

1. Download or clone the repository.
2. Open `index.html` in your preferred browser.
3. Start using CalcX immediately.

### Option 2: Serve locally

If you prefer running the app through a local web server:

```bash
cd CalcX
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Usage

- Use the calculator panel for arithmetic and scientific expressions.
- Switch between Standard, Scientific, and Engineering modes using the mode controls.
- Explore conversion tools from the navigation menu.
- Use the utility directory to access calculators for percentage, age, finance, statistics, and other everyday needs.
- Clear results and manage recent history from the session panel.
